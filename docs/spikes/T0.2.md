# T0.2 — Cô lập metadata skill ở main + preload cho subagent

**Quyết định:** GO — cô lập giữ được **theo mặc định**, nhưng **không phải ranh giới cưỡng chế**.
Claude Code `2.1.325`, 2026-11-17.

## Thiết lập

Plugin fixture từ [T0.1](T0.1.md): skill `spike-specialist` (canary trong body `SPECIALIST-BODY-CANARY-7F3A`), skill `spike-entry` (canary trong body `ENTRY-BODY-CANARY-19C2`), agent `spike-backend` với `skills: [spike-specialist]` và `disallowedTools: Skill`. Loại trừ user settings (`--setting-sources project,local`) để chỉ nạp plugin fixture + builtin.

## Lệnh thực tế

```bash
# Lần 1: main tự kiểm tra context (không dùng tool), sau đó gọi agent để kiểm tra context của nó
claude -p --no-session-persistence --setting-sources project,local --plugin-dir <plugin> \
  --model sonnet --effort medium --allowedTools "Task Agent" --output-format stream-json --verbose \
  "Step 1, WITHOUT using any tool: does SPECIALIST-BODY-CANARY / ENTRY-BODY-CANARY appear ...? Step 2: dispatch omi-spike:spike-backend ..."

# Lần 3: main có thể chủ động nạp body của skill chuyên môn không?
claude -p --no-session-persistence --setting-sources project,local --plugin-dir <plugin> \
  --model haiku --allowedTools "Skill" --output-format stream-json --verbose \
  "Invoke the skill omi-spike:spike-specialist using the Skill tool, then quote ... CANARY"
```

## Giới hạn

- **Description** của skill chuyên môn luôn hiển thị với main (tài liệu: description được nạp, body chỉ nạp khi gọi). Phần description bị cắt ở 1.536 ký tự.
- Main có thể nạp body của bất kỳ plugin skill nào qua tool Skill. Các option đã được tài liệu hóa không giải quyết được: `disable-model-invocation: true` đồng thời **chặn preload vào subagent**; `user-invocable: false` vẫn cho model gọi; `skillOverrides` **không** áp dụng cho plugin skill.
- Chưa kiểm tra `/context` ở chế độ tương tác (harness không tương tác); khuyến nghị xác nhận thủ công ở T1.4/T1.5.

## Khuyến nghị

Giữ skill chuyên môn preload qua `skills:` với description trung tính, an toàn cho định tuyến ("chỉ dành cho `<agent>`"); entry skill của Coordinator dặn không gọi skill chuyên môn. Bộ quy tắc chuyên môn đặt trong `resources/role-rules/<role>/` (không tự khám phá) và agent đọc theo đường dẫn tường minh. Đặt `disallowedTools: Skill` cho agent có phạm vi hẹp.

## Fallback

Nếu bắt buộc loại trừ tuyệt đối khỏi main: chuyển toàn bộ nội dung chuyên môn vào `resources/` và để agent `Read` theo đường dẫn (không đăng ký skill). Xác minh ở T1.4 bằng cùng phương pháp canary.
