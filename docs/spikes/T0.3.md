# T0.3 — Thực thi trong worktree / cô lập cwd

**Quyết định:** GO — dùng **adapter cwd tường minh** (mỗi task một tiến trình `claude -p --agent <plugin>:<agent>`, khởi chạy bên trong worktree OMI của nó). Subagent do Coordinator giao việc cũng ở đúng phạm vi nhưng vướng quyền.
Claude Code `2.1.325`, Git `2.55.0.windows.5`, 2026-11-17.

## Thiết lập

```bash
git init --bare -b main origin.git && git clone origin.git repo        # fixture cục bộ, không dùng GitHub
# repo: AGENTS.md commit trên main; develop được push từ main
git fetch origin develop; BASE=$(git rev-parse origin/develop)          # 1bc0d5b
git worktree add ../.omi-worktrees/repo/101 -b feature/101-a origin/develop
git worktree add ../.omi-worktrees/repo/102 -b feature/102-b origin/develop
# marker sở hữu cho mỗi worktree: .omi-owner.json {"issue":N,"baseSha":"<BASE>","owner":"omi-spike"}
```

## Lệnh thực tế

```bash
# A. Adapter cwd tường minh, hai task song song
for n in 101 102; do ( cd .omi-worktrees/repo/$n && claude -p --no-session-persistence \
  --setting-sources project,local --plugin-dir <plugin> --agent omi-spike:spike-backend \
  --permission-mode acceptEdits --allowedTools "Bash(pwd)" "Bash(git rev-parse *)" "Bash(git status *)" \
  --output-format stream-json --verbose "Create file task-$n.txt ... run pwd; git rev-parse --abbrev-ref HEAD; git status --short" ) & done; wait

# B. Coordinator ở main checkout giao hai subagent song song làm việc ở đường dẫn worktree tuyệt đối
cd repo && claude -p ... --add-dir <wt101> <wt102> --permission-mode acceptEdits \
  --allowedTools "Agent" "Task" "Bash(cd *)" "Bash(pwd)" "Bash(git rev-parse *)" --forward-subagent-text \
  "Dispatch TWO omi-spike:spike-backend subagents in parallel ... Write nothing outside your assigned worktree."

git worktree list; git status --short --untracked-files=all; ls <từng worktree>
```

## Hành vi quan sát được

| Kiểm tra | A (cwd tường minh) | B (subagent được giao) |
| --- | --- | --- |
| cwd của phiên/agent | `init.cwd` = worktree; `pwd` → `.../.omi-worktrees/repo/10N` | subagent kế thừa cwd của main (main checkout) |
| Branch báo cáo | `feature/101-a`, `feature/102-b` | không lấy được: lệnh ghép `cd <wt> && pwd && git ...` bị **từ chối quyền** dù có `Bash(cd *)` |
| File được ghi | `task-101.txt` chỉ ở wt101, `task-102.txt` chỉ ở wt102 | `sub-101.txt` chỉ ở wt101, `sub-102.txt` chỉ ở wt102 (Write theo đường dẫn tuyệt đối) |
| `git status --untracked-files=all` của main checkout | sạch | sạch |
| `git worktree list` sau khi chạy | không đổi (3 mục) | không đổi (3 mục) |
| Model | agent chính `claude-sonnet-5-5` | main + 2 subagent `claude-sonnet-5-5` |

## Kiểm thử / bằng chứng

Trace `t03_A_101.jsonl`, `t03_A_102.jsonl`, `t03_B.jsonl` (scratchpad); danh sách filesystem ở trên được ghi ngay sau khi chạy.

## Giới hạn

- Việc giới hạn trong B **dựa vào prompt và quyền**, không phải sandbox: subagent có Write và `--add-dir` cho cả hai worktree vẫn có thể ghi sang task kia. A — cwd theo tiến trình + `--add-dir` chỉ một worktree — chặt hơn.
- `.omi-owner.json` hiện là untracked (`?? .omi-owner.json`); runtime phải đưa nó vào `.git/info/exclude` hoặc đặt ngoài cây thư mục, nếu không sẽ chặn `git worktree remove` sạch (xem T0.8).
- **Chưa test** `isolation: worktree` trong frontmatter agent; theo tài liệu nó tạo worktree tạm do Claude quản lý, rẽ nhánh từ default branch — xung đột với quyền sở hữu của OMI/base `origin/develop`. Không dùng.
- Đường dẫn Windows hoạt động với dấu `/` trong Git Bash; chưa test launcher PowerShell ở đây (T7.3).

## Khuyến nghị

Runtime `omi` khởi chạy agent thành tiến trình riêng với `cwd=<worktree đã xác thực>`, `--agent <plugin>:<role>`, không có `--add-dir` nào ngoài worktree, `--allowedTools` giới hạn, `--output-format stream-json` (để quan sát model). Tối đa 3 tiến trình đồng thời theo policy.

## Fallback

Nếu mỗi agent một tiến trình quá tốn kém: Coordinator giao việc (B) **tuần tự**, dùng đường dẫn tuyệt đối, kèm hook PreToolUse từ chối ghi ra ngoài worktree được giao.
