## Thiết lập

`claude --version` → `2.1.325 (Claude Code)`; tài liệu yêu cầu ≥ `2.1.277` để đọc AGENTS.md trực tiếp qua plugin builtin `cc-plugin-agents-md@builtin` (có trong `init.plugins`). Máy này không có `~/.claude/CLAUDE.md`. Lần chạy này dùng user settings mặc định (không hạn chế).

| Trường hợp | File |
| --- | --- |
| c1 | `AGENTS.md` ("AGENTS-CANARY-55D1 from AGENTS.md") |
| c2 | c1 + `CLAUDE.md` ("CLAUDE-CANARY-88E0 from CLAUDE.md") |
| c3 | c1 + `CLAUDE.md` chứa `CLAUDE-CANARY-88E0 ...` và `@AGENTS.md` |

## Lệnh thực tế

```bash
for c in c1 c2 c3; do ( cd $c && claude -p --no-session-persistence --plugin-dir <plugin> --model haiku \
  --allowedTools "Agent" "Task" --output-format stream-json --verbose \
  "WITHOUT tools: quote verbatim every line containing AGENTS-CANARY or CLAUDE-CANARY (or NONE). Then dispatch omi-spike:spike-backend with the same question ..." ) & done; wait
```

## Giới hạn

- Bất kỳ `CLAUDE.md`, `.claude/CLAUDE.md` hoặc `CLAUDE.local.md` nào ở cwd **hoặc thư mục cha** sẽ âm thầm tắt AGENTS.md theo thiết lập mặc định `claude-md-or-agents-md` — kể cả `CLAUDE.local.md` cá nhân của developer.
- Theo tài liệu: AGENTS.md có thể bị bỏ qua ở phiên đầu tiên sau khi nâng cấp từ ≤ `2.1.276`, hoặc nếu plugin builtin bị tắt; hook `InstructionsLoaded` không chạy cho AGENTS.md được đọc nguyên bản.
- Subagent có `omitClaudeMd: true` khởi động không có các file này (chưa test).

## Khuyến nghị

AGENTS.md là chuẩn; không sinh CLAUDE.md. `omi doctor` nên kiểm tra: Claude Code ≥ 2.1.277, plugin builtin `cc-plugin-agents-md` đang bật, và cảnh báo nếu có CLAUDE.md/CLAUDE.local.md ở hoặc trên thư mục gốc repo.

## Fallback

Khi doctor phát hiện CLAUDE.md (hoặc host cũ/không hỗ trợ), đề xuất — chỉ khi được phê duyệt rõ ràng — một `CLAUDE.md` tối thiểu chứa `@AGENTS.md` (trường hợp c3, đã xác minh), hoặc thiết lập cấp user `pluginConfigs["cc-plugin-agents-md@builtin"].options.instructionFiles = "claude-md-and-agents-md"` (có trong tài liệu, chưa test).
