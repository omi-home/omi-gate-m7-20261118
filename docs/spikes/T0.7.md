# T0.7 — Branch protection theo visibility / plan của repo

**Quyết định:** **GO cho repo public** (cưỡng chế phía server hoạt động, kể cả với admin) · **NO-GO cho repo private trên org Free** (không bật được protection/ruleset; push thẳng thành công) → cần PO chấp nhận rủi ro, chuyển public, hoặc nâng gói.
Org `omi-home` gói **Free**, 2026-11-17.

## Thiết lập

- Public: `omi-home/omi-spike-p0-20261117`; private: `omi-home/omi-spike-p0-private-20261117`. Tài khoản là admin của cả hai repo.
- Classic protection: bắt buộc PR (0 approval), `enforce_admins: true`.
- Ruleset `omi-protect-develop`: rule `pull_request` + `non_fast_forward` trên `refs/heads/develop`.

## Lệnh thực tế

```bash
echo '{"required_status_checks":null,"enforce_admins":true,"required_pull_request_reviews":{"required_approving_review_count":0},"restrictions":null}' \
  | gh api -X PUT repos/<repo>/branches/develop/protection --input -
echo '<ruleset json>' | gh api -X POST repos/<repo>/rulesets --input -
gh api -X PUT repos/<repo>/contents/direct-push.txt -f branch=develop -f message="direct push attempt" -f content=<base64>
# cô lập classic protection trên repo public:
gh api -X DELETE repos/omi-home/omi-spike-p0-20261117/rulesets/27435217
gh api -X PUT repos/omi-home/omi-spike-p0-20261117/contents/direct-push.txt -f branch=develop ...
```

## Hành vi quan sát được

| Kiểm tra | Public | Private (Free) |
| --- | --- | --- |
| Classic protection `develop` | OK: `enforce_admins=true`, bắt buộc PR | **403** "Upgrade to GitHub Pro or make this repository public to enable this feature." |
| Ruleset `develop` | OK: id `27435217`, `enforcement: active` | **403** cùng thông báo |
| Push thẳng vào `develop` (admin, có ruleset + classic) | **Bị chặn** 409 "Repository rule violations found — Changes must be made through a pull request." | **Thành công** — commit `744adea` |
| Push thẳng, chỉ còn classic (đã xóa ruleset) | **Bị chặn** 409 "Could not create file: Changes must be made through a pull request." | — |

## Kiểm thử / bằng chứng

Output lệnh trong transcript phiên. Repo private có commit `direct-push.txt` trên `develop` làm bằng chứng không có cưỡng chế.

## Giới hạn

- Push thử qua contents API (REST); chưa thử `git push` qua SSH/HTTPS, nhưng cả hai cùng chịu protection phía server.
- Chưa test required status checks, required reviews > 0, quyền bypass của ruleset, hay protection cho `main`.
- Repo public hiện còn classic protection trên `develop` (đã xóa ruleset).

## Khuyến nghị

- `omi doctor` đọc visibility + gói org + trạng thái protection; với repo private trên Free phải báo rõ **"không có cưỡng chế phía server"**.
- Với repo public: dùng classic protection hoặc ruleset cho `main` và `develop`, bật `enforce_admins`.

## Fallback

Repo private trên Free: hook cục bộ + CI check để **phát hiện** (không ngăn chặn), ghi rủi ro vào README/doctor, yêu cầu PO chấp nhận; hoặc chuyển repo public / nâng gói Team nếu bắt buộc cưỡng chế.
